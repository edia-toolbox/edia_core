## EDIA Samples

# Additional steps
In order to run the sample in the editor, a sample environment is required.
This is provided in the EDIA Samples package.

1. Import the package 'Starter room'
2. Link the scene in the `Edia-SceneLoader` object in the hierarchy.
3. Add the scene to the build profiles 'scene list'.

Now the project should run without errors.
